# zihjyunderek.github.io

Personal portfolio of **Zih-Jyun (Derek) Huang** (黃子竣). Spatial statistics, urban analytics, and quantitative risk.

**Live:** https://zihjyunderek.github.io

Built with [Astro](https://astro.build): fully static, SEO-first, zero client JS. Design: light academic editorial theme, two typefaces (Source Serif 4 for text, JetBrains Mono for data), single deep-navy accent. Sections are numbered macro to micro in the source (01 profile to 05 contact) as an organizing convention; the numbers are not shown in the UI.

## Retention policy: Only public

Everything tracked in this repo is publishable as-is. There is no private material and no private/public split. `.gitignore` excludes only generated artifacts (`dist/`, `node_modules/`), secrets (`.env*`, keys), and local agent context.

## The two things you'll actually edit

**Add a project**: drop a `.md` file in `src/content/projects/`:

```markdown
---
title: "My New Project"
tagline: "One sentence. Also the page meta description."
domain: spatial            # spatial | urban | finance | engineering
stack: ["Python", "..."]
stats:
  - { value: "31", label: "cities" }
featured: false            # true = pinned first on home page (home shows 6)
order: 13                  # sort position (lower = first)
status: public             # public | private | research
repo: "https://github.com/zihjyunderek/..."   # optional; private repo links are fine
---

Markdown body renders as the project detail page.
```

**Update personal details**: edit `src/config.ts` (name, email, GitHub, LinkedIn) and `src/data/profile.ts` (experience, education, certificates, skill bars, headline stats).

**Rebuild the CV**: `python scripts/build_cv.py` regenerates `public/cv/ZihJyunHuang_CV_en.pdf` from the data block at the top of that script. It auto-fits the type scale to exactly one page and fails if nothing fits, so a CV that grows past the limit is caught before it ships. Typography is Lato only, greyscale only; the four subset TTFs ship in `scripts/fonts/` (OFL, license included) so nothing needs installing. Keep the script and `src/data/profile.ts` in sync.

**Attachments**: only documents that may be public are linked, currently the NCCU thesis, the CFA Research Challenge report, and the three certificate licenses, under `public/attachments/`. Diplomas and employer deliverables are excluded on purpose (identity documents, NDA); do not add an `attachments` entry pointing at a file that cannot be published.

## Development

```bash
npm install
npm run dev       # dev server at http://localhost:4321 (hot reload)
npm run build     # static output to ./dist
npm run preview   # serve the production build locally

python scripts/build_cv.py    # regenerate the CV PDF (needs: pip install reportlab)
```

Windows one-click: `scripts/dev.bat` (dev server) or `scripts/preview.bat` (production build + preview). Both auto-install on first run. Full workflow in Chinese: `docs/local-dev.md`.

## Deploy

GitHub Pages builds from source on every push to `main`.

One-time setup: GitHub, Settings, Pages, Source, GitHub Actions.

```bash
git add -A
git commit -m "..."
git push          # CI builds and deploys; live in 1-2 minutes
```

Run `scripts/preview.bat` before pushing to see the exact production build locally first. A build that fails locally will also fail in CI.

## SEO

- Per-page `<title>`, meta description, canonical URL (auto-derived from page path)
- Open Graph and Twitter card with `og-default.png`
- JSON-LD: `Person` and `WebSite` on home; `SoftwareSourceCode` and `BreadcrumbList` on project pages
- `sitemap-index.xml` via `@astrojs/sitemap`

After first deploy: verify the domain in [Google Search Console](https://search.google.com/search-console) and submit the sitemap URL.

## Maintenance

- Dependabot opens monthly update PRs for npm packages and GitHub Actions (`.github/dependabot.yml`).
- Dependencies are pinned via `package-lock.json`; CI installs with `npm ci`.
- `package.json` is `private` (never publishable to npm) and declares `engines.node >= 20`.
